# 两项 AI 工作流展示

围绕图表生成和 Excel 智能翻译的两项整理副本，展示问题定义、技术取舍与产品化思路。

## 项目一览

| 项目 | 关注点 | 副本范围 |
| --- | --- | --- |
| Solution Diagram Workflow | 语义规则、确定性图表渲染与可复用 Skill | 最终 Skill 和支撑其设计的说明，非完整原项目镜像 |
| Excel Intelligent Translation | 格式保护、本地词典与线上模型、成本与稳定性 | 经裁剪的设计与代码展示，非可直接分发的软件包 |

两项内容承担不同的展示角色：前者侧重工作流如何收敛，后者侧重翻译 Demo 的设计与产品化取舍。

## 阅读入口

## 如何理解这些副本

- 副本由既有项目筛选整理，保留的内容不是原项目的全部资料。
- 图表项目围绕 `Human Factors Diagram Renderer` 的规则与渲染思路展开。
- Excel 项目关注复杂格式、翻译路径和可打包工具的设计取舍。
- 本仓库提供展示与阅读材料，没有面向外部用户的通用安装或部署承诺。
