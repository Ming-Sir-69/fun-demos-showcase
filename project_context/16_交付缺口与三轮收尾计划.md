# 交付缺口与三轮收尾计划

## 1. 当前判断

两个小项目副本已经完成项目冻结、敏感边界收缩和第二轮结构减法。

现在距离交付这个大项目，主要缺的已经不是“继续删文件”，而是：

1. 大项目自己的入口层还不够完整
2. 大项目对外阅读路径还没有正式收口
3. 两个小项目与大项目之间的关系说明还不够明确
4. 交付前的一次全局一致性检查还没有做

## 2. 当前未完成项

### A. 大项目入口层未完成

当前问题：

1. 根目录 `README.md` 还偏“过程说明”，还不是最终交付入口
2. 缺少一个更明确的总阅读顺序文件
3. `selected_projects/README.md` 过于简短，无法承担项目总导航作用

交付前需要达到：

1. 人类读者能在 3 分钟内理解这个大项目是什么、先看什么、为什么看这两个子项目
2. AI 能明确知道应该从哪些文件开始读、哪些是原始证据、哪些是整理入口

### B. 大项目与两个小项目的关系说明未完成

当前问题：

1. 还没有一个正式文件说明“大项目展示的是什么，小项目分别承担什么证据角色”
2. `Solution Diagram Workflow` 与 `Excel Intelligent Translation` 的互补关系还没有在大项目入口层正式落地

交付前需要达到：

1. 一眼能看出为什么是这两个项目，而不是更多项目
2. 一眼能看出 `Solution` 更偏探索与一手材料，`Excel` 更偏完整度与产品化能力

### C. 顶层阅读引导未完成

当前问题：

1. 还没有正式区分“给人读”和“给 AI 读”的推荐路径
2. 还没有把 `transcripts/` 的作用作为作者一手工作材料明确固化到大项目入口层

交付前需要达到：

1. 人类读者能走短路径
2. AI 读者能走证据路径
3. 两条路径互不冲突

### D. 全局一致性检查未完成

当前问题：

1. 大项目的部分旧文档仍然保留收缩前语境
2. 顶层入口与子项目入口之间还没有做最后一次对齐
3. 还没有做最终一致性检查

交付前需要达到：

1. 顶层说法、子项目说法、上下文说法不互相打架
2. 没有明显误导读者的旧阶段表述
3. 敏感内容边界再次确认无误

## 3. 三轮收尾计划

### 第 1 轮：完成大项目入口层

本轮目标：

1. 把大项目根目录入口改成真正可交付的阅读入口
2. 补齐大项目总导航
3. 明确两个子项目的角色分工

本轮建议产出：

1. 更新根目录 `README.md`
2. 强化 `selected_projects/README.md`
3. 将顶层阅读引导整合进根目录 `README.md`

本轮完成标准：

1. 不看聊天记录，也能知道这个大项目怎么读
2. 能清楚知道两个子项目分别看什么
3. 能清楚知道 `transcripts/` 在整个交付中的位置
4. 人类读者和 AI 读者的区别至少已经被点出来，但不要求在这一轮彻底展开

### 第 1 轮允收线

做到以下程度即可进入下一轮：

1. 根目录 `README.md` 已经从“过程说明”升级为“交付入口”
2. `selected_projects/README.md` 已能说明两个子项目的分工
3. 顶层阅读引导已整合进根目录 `README.md`
4. 人类读者可以只靠短文本完成第一轮判断
5. AI 读者已经被明确提示应优先看哪些证据层文件

### 第 2 轮：完成双通道阅读设计与一致性对齐

本轮目标：

1. 正式固化“人类短路径”和“AI 证据路径”
2. 校准顶层和两个子项目之间的表述一致性
3. 补齐必要但还没正式落地的交付边界说明

本轮建议产出：

1. 完成 `06`、`07`、`08` 中至少需要落地的正式内容
2. 校准顶层文档中的旧阶段表述
3. 形成一份全局阅读与分析边界说明

本轮完成标准：

1. 人和 AI 各自的阅读顺序清楚
2. 项目之间的分工不重复、不冲突
3. 顶层文件不再停留在“整理中”口吻
4. `transcripts/` 作为作者一手材料的定位已在顶层正式固化

### 第 2 轮允收线

做到以下程度即可进入最终冻结轮：

1. `06`、`07`、`08` 已从占位文件变成正式规则文件
2. 顶层和子项目入口对“人类短路径 / AI 证据路径”的说法一致
3. 已明确哪些内容适合主观经验判断，哪些内容适合长上下文客观分析
4. 引导文件没有越界到替读者评价作者本人
5. 顶层旧阶段口吻已基本清理完成

### 第 3 轮：最终检查与整理结束

本轮目标：

1. 做最终一轮全局检查
2. 确认没有多余噪音文件和明显错误表述
3. 将大项目标记为整理阶段结束版本

本轮建议产出：

1. 完成 `09` 的最终交付说明
2. 记录整理阶段结束状态
3. 明确未完成的人工阅读测试不由 AI 冒充关闭

本轮完成标准：

1. 大项目入口可直接对外阅读
2. 两个子项目入口可直接独立阅读
3. 证据层、引导层、边界层完整闭环
4. 本项目可以在三轮内结束，不再继续发散

### 第 3 轮允收线

做到以下程度即可宣布本轮整理施工结束：

1. `09` 已完成最终交付说明
2. 已新增一份整理阶段结束记录
3. 顶层入口、双通道设计、两个子项目入口彼此一致
4. 没有明显误导性的旧表述残留
5. 没有新的敏感边界问题暴露
