## 2026-06-20
- **架构决策：AI + 脚本双层的分离（核心转折点）**
- 背景：chart1 经过 5 轮修复仍出现出口方向选择错误、入口悬浮、线重叠、斜线路由问题。根因是让 AI 同时负责"内容决策 + 格式输出"——前者它擅长（定义多少层、放什么节点、连线语义），后者它不擅长（坐标计算、方式点规划、style 字符串、总线检测）。
- 决定：拆为两层——
  - **AI 层（决策）**：输出 JSON 结构描述（层/节点/连线/图标映射），用平价模型即可
  - **脚本层（生成）**：`build_diagram.py` 吃 JSON → 执行全部规则（减法公式、出口方向几何判断、总线合并、颜色映射、图标 base64 嵌入）→ 吐出完整 drawio XML → 自动跑 C1-C9 验收
- 脚本的确定性使**产出稳定**，平价的模型让**成本可控**。AI 只做"决策"，不做"格式计算"。
- 该方案对标 ProcessOn 的 Mermaid→渲染模式，但我们的规则全部自控（颜色/间距/路由/字体），不受第三方风格限制。
- 当前多场景验证（chart1~4）继续通过指南层跑，完成后进入模板层开发。

## 2026-06-17 draw.io 图片嵌入方式验证（3 方案实测）

- **决策**：draw.io 中嵌入图片的唯一可用方式是 HTML `<img>` 标签嵌入到 `value` 属性中
- **实测结果**：
  1. ✅ `value="&lt;img src=&quot;data:image/png;base64,...&quot;/&gt;<b>标题</b><br>描述"` — 成功
  2. ❌ 独立 `shape=image;image=data:image/png;base64,...` cell — 占位符
