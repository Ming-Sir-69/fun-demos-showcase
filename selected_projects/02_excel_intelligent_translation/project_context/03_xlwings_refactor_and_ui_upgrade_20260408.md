## 2. 架构演进与核心改动 (Architecture Updates)

### 2.1 模块化解耦
* **切分逻辑独立**：
  - `chunking_zh.py`：针对中文源文本，采用**按字符数**（默认 500 字符）切片，保证中文语义厚度。
  - `chunking_en.py`：针对英文源文本，采用**按单词数**（默认 300 单词）切片，彻底解决了英翻中时因“字母数切片”导致语义破碎、瞬间并发打满 API 限流的致命痛点。
* **提示词工程独立 (`prompts.py`)**：
  - 移除了 LLM 对 `\n` 和 `|||` 等格式拼接的思考负担。
  - 现在的 Prompt 强制约束模型输出纯正的 JSON 字典（`{"原文": "译文"}`），并在英翻中提示词中增加了工业料号、公差符号的防呆约束。

### 2.2 灵活的 4 种排版模式
主程序 (`main_pipeline_full.py`) 现已支持四种无缝切换的翻译模式：
1. `zh_to_en`：纯中翻英
2. `en_to_zh`：纯英翻中
3. `zh_to_en_bilingual`：双语（中文原文在上，英文译文在下）
4. `en_to_zh_bilingual`：双语（中文译文在上，英文原文在下）
*注：双语拼接的排版动作已全部从 LLM 转移到 Python 内存中执行，实现了 100% 的格式稳定。*

### 2.3 xlwings 性能优化
通过 `all_values = used_range.value` 的 2D 数组内存映射以及 `set()` 哈希表去重，将万级单元格的遍历与合并单元格判定从数十万次的 IPC 跨进程通信，降维至仅在内存中操作，路由分发耗时从数分钟压缩至 ~30 秒级别。

## 3. 终端交互升级 (Terminal UI Upgrades)
为了提供极致的极客级终端反馈，我们在命令行交互上做出了以下增强：
* **Live Timer (全链路动态计时)**：使用后台 Daemon 线程和 ANSI 转义字符 (`\r\033[K`) 实现了帧率高达 20 FPS 的平滑秒表，实时覆盖从副本生成、Excel读取、路由分发到单元格覆写的全流程。
* **批次级监控 (Batch-level Logging)**：
  大模型翻译阶段不再是单一进度条，而是详细的逐批次（如 `[批次 3/11]`）流水账。包含每个批次的精准耗时、处理条数、以及状态（✅成功、❌失败）。
* **智能退避可视化**：当触发 Moonshot/DeepSeek 等 API 的 429 限流时，终端会显示醒目的 `⚠️` 并进入带小数点的动态倒计时读秒，结束后自动 `🔄 重新发送`，防止死锁焦虑。
