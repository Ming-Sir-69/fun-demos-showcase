# Selected Projects

本目录存放两个正式对外项目的整理副本。

它们不是重复展示，而是分别承担不同类型的证据角色。

## 怎么理解这两个项目

1. `01_solution_diagram_workflow`
作用：更适合看探索路径、关键决策、Skill 化收口，以及原始长文本工作材料。

2. `02_excel_intelligent_translation`
作用：更适合看已跑通 Demo 的完整度、稳定性、成本意识和产品化推进思路。

## 人类短路径

如果你只想快速判断这两个项目各自的展示价值，建议按这个顺序读：

1. `01_solution_diagram_workflow/README.md`
2. `02_excel_intelligent_translation/README.md`

进入任一小项目后，先按该项目 `README.md` 的推荐顺序阅读。不要从源码、转录文件或 `project_context/` 里随机开始，因为这些文件承担的是证据层角色，不是首屏入口。
